# Spawn Selector — Fabric 26.2

Мод открывает обязательный выбор стартовой территории при первом входе игрока на сервер. В интерфейсе представлены ровно три центральные карточки:

1. **Европа** — лесная территория.
2. **Африка** — равнинная территория.
3. **Австралия** — горная территория.

Каждая карточка показывает изображение, описание, численность игроков и кнопку выбора. Свободного выживания и выбора без команды больше нет. После выбора мод назначает соответствующую scoreboard-команду, группу LuckPerms и безопасную точку появления.

## Сборка

- Minecraft 26.2
- Fabric Loader и Fabric API из `gradle.properties`
- Java 25

В Windows: `gradlew.bat build`  
В Linux/macOS: `./gradlew build`

Готовый JAR появится в `build/libs`.

## Администраторские команды

- `/spp list` — список точек.
- `/spp set 1 <позиция>` — установить координаты первой территории на текущую позицию.
- `/spp set 2 <позиция>` — установить координаты второй территории.
- `/spp set 3 <позиция>` — установить координаты третьей территории.
- `/spp setname <номер 1–3> <название>` — изменить название.
- `/spp teams` — показать численность команд.
- `/spp reset <игрок>` — сбросить выбор игрока и убрать его из команды.

Команды доступны операторам. `/spp set` устанавливает точку по текущей позиции игрока и поэтому выполняется только из игры; остальные команды можно вызывать из консоли, если они не требуют присутствия игрока.

## Конфигурация

После первого запуска появится `config/spawn-selector/spawnpoints.json`.

- `maxPlayersPerTeam: 0` отключает абсолютный лимит команды.
- `maxTeamImbalance: 3` запрещает выбор, который создаст перевес более трёх игроков относительно самой малочисленной команды.
- `radius` задаёт радиус поиска безопасной точки вокруг координат территории.
- `spawnPoints` содержит название, описание, изображение, координаты и имя scoreboard-команды каждой из трёх территорий.
- `menuText` содержит настраиваемые заголовки, подписи карточек, тексты кнопок, шаблоны численности, ошибки и цвета.

Текст меню передаётся игрокам с сервера. Если параметры `menuText` отсутствуют или имеют значение `null`, мод восстанавливает значения по умолчанию.

## Изображения меню

Изображения находятся в `src/main/resources/assets/spawnselector/textures/gui/spawn_selector/`:

- `forest.png` — Европа.
- `plains.png` — Африка.
- `mountains.png` — Австралия.

Карточки используют широкое изображение сверху, описание ниже и отдельную кнопку выбора. Изображения не повторяются в интерфейсе.

## Важные замечания

- Данные выбранных игроков хранятся в `config/spawn-selector/spawndata.json`.
- Если конфиг повреждён, исходный файл сохраняется как `*.broken`, затем создаётся конфигурация по умолчанию.
- При сбросе выбора команда игрока очищается.
- Перед установкой в рабочий мир соберите мод и проверьте его на сервере Fabric 26.2.
