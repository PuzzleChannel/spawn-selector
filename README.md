# Spawn Selector — Fabric 26.2

Мод открывает обязательный выбор стартовой территории при первом входе игрока на сервер. В интерфейсе представлены ровно три центральные карточки:

1. **Европа** — лесная территория.
2. **Африка** — равнинная территория.
3. **Австралия** — горная территория.

Каждая карточка показывает изображение, название, описание, численность игроков и кнопку выбора. После выбора мод назначает соответствующую scoreboard-команду, группу LuckPerms и безопасную точку появления.

## Сборка

- Minecraft 26.2
- Fabric Loader и Fabric API из `gradle.properties`
- Java 25

В Windows: `gradlew.bat build`  
В Linux/macOS: `./gradlew build`

Готовый JAR появится в `build/libs`.

## Администраторские команды

- `/spp list` — список точек.
- `/spp set 1 <позиция>` — установить координаты первой территории на текущую позицию.
- `/spp set 2 <позиция>` — установить координаты второй территории.
- `/spp set 3 <позиция>` — установить координаты третьей территории.
- `/spp setname <номер 1–3> <название>` — изменить название.
- `/spp teams` — показать численность команд.
- `/spp reload` — перечитать серверный конфиг и обновить текст у игроков, у которых сейчас открыто меню.
- `/spp reset <игрок>` — сбросить выбор игрока и убрать его из команды.

Команды доступны операторам. `/spp set` устанавливает точку по текущей позиции игрока и поэтому выполняется только из игры; остальные команды можно вызывать из консоли, если они не требуют присутствия игрока.

## Серверный конфиг и полный контроль над текстом

После первого запуска появится файл:

`config/spawn-selector/spawnpoints.json`

**Все надписи экрана выбора задаются сервером** и передаются игрокам вместе с меню. Клиентские файлы локализации не переопределяют серверные значения.

### Названия и описания карточек

В массиве `spawnPoints` настройте для каждой из трёх территорий:

- `name` — название, которое увидят игроки.
- `description` — описание под картинкой.
- `image` — путь к изображению в ресурсах мода.
- `team` — имя scoreboard-команды и группа LuckPerms, назначаемая после выбора.
- `color` — цвет scoreboard-команды.
- `x`, `y`, `z`, `yaw` — координаты и направление появления.

### Весь текст интерфейса

В объекте `menuText` доступны параметры:

| Ключ | Что изменяет |
| --- | --- |
| `windowTitle` | Служебный заголовок окна |
| `headerTitle` | Главный заголовок |
| `headerSubtitle` | Подзаголовок под главным заголовком |
| `chooseButton` | Текст кнопки выбора на карточке |
| `footerHint` | Подсказка внизу экрана |
| `previewPlaceholder` | Текст-заполнитель, когда изображение территории недоступно |
| `players` | Шаблон численности без лимита |
| `playersLimited` | Шаблон численности с лимитом |
| `unavailable` | Подпись недоступной территории |
| `unavailableMessage` | Сообщение при нажатии на недоступную территорию |
| `errorLoad` | Ошибка загрузки списка территорий |
| `errorTeleport` | Ошибка телепортации |
| `errorInvalidChoice` | Ошибка некорректного выбора |
| `errorTeamUnavailable` | Ошибка отсутствующей команды |
| `errorTeamFull` | Сообщение о заполненной территории |
| `errorTeamImbalanced` | Сообщение о дисбалансе численности |
| `errorInvalidY` | Ошибка координаты высоты |
| `errorNoSurface` | Ошибка поиска безопасной поверхности |
| `errorAssignTeam` | Ошибка назначения scoreboard-команды |
| `errorSpawnpoint` | Ошибка установки точки возрождения |

В `players` и `playersLimited` используются шаблоны `{count}` и `{max}`. В `errorTeamFull` и `errorTeamImbalanced` можно использовать `{name}`, `{count}` и `{max}`.

Цвета рамок и фона карточек в текущем интерфейсе назначаются темам территорий; параметры `styleAccent`, `stylePanel`, `styleCard`, `styleConfirmButton` и `styleBackButton` сохранены для совместимости со старым конфигом, но текущими карточками не используются.

**Как применить изменения без перезапуска:** отредактируйте `spawnpoints.json`, сохраните файл и выполните в игре или консоли `/spp reload`. Мод перечитает конфиг и обновит меню у игроков, которые сейчас выбирают территорию. Новые игроки также сразу увидят обновлённый текст. Если конфиг отсутствует или повреждён, мод восстановит его из значений по умолчанию; перед восстановлением повреждённый файл копируется в `spawnpoints.json.broken`.

## Важные замечания

- Данные выбранных игроков хранятся в `config/spawn-selector/spawndata.json`.
- При сбросе выбора команда игрока очищается.
- Перед установкой в рабочий мир соберите мод и проверьте его на сервере Fabric 26.2.
