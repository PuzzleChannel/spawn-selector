# Spawn Selector — Fabric 26.2

Мод добавляет обязательный выбор места появления при первом входе на сервер:
1. Одна из трёх командных точек.
2. Свободное выживание без команды — случайная безопасная точка суши в диапазоне X/Z от -10 000 до +10 000.

## Сборка

- Minecraft 26.2
- Fabric Loader и Fabric API из `gradle.properties`
- Java 25

В Windows: `gradlew.bat build`
В Linux/macOS: `./gradlew build`

Готовый JAR появится в `build/libs`.

## Администраторские команды

- `/spp list` — список точек.
- `/spp set 1 <позиция>` — установить координаты первой командной точки на текущую позицию.
- `/spp set 2 <позиция>` — установить вторую точку.
- `/spp set 3 <позиция>` — установить третью точку.
- `/spp setname <номер 1–3> <название>` — изменить название.
- `/spp teams` — показать численность команд.
- `/spp reset <игрок>` — сбросить выбор игрока и убрать его из команды.

Команды доступны операторам и консоли сервера.

## Конфигурация

После первого запуска появится `config/spawn-selector/spawnpoints.json`.

- `maxPlayersPerTeam: 0` отключает абсолютный лимит команды.
- `maxTeamImbalance: 3` запрещает выбор, который создаст перевес более трёх игроков относительно самой малочисленной команды.
- `radius` задаёт радиус поиска безопасной точки вокруг координат командного спавна.

Четвёртый вариант всегда использует диапазон X/Z от -10 000 до +10 000. Мод пробует ограниченное количество случайных координат и отбрасывает воду, лаву/огонь, опасные блоки, пустоту под ногами и места без свободного пространства. Если подходящее место не найдено, выбор не фиксируется и игрок может попробовать снова.

## Превью изображений

Клиентский интерфейс показывает встроенную пиксельную заглушку, пока соответствующий PNG отсутствует. Чтобы заменить её, добавьте изображения 16:9 в:

`src/main/resources/assets/spawnselector/textures/gui/spawn_selector/`

Используйте имена `forest.png`, `plains.png`, `mountains.png`. Пути задаются в `config/spawn-selector/spawnpoints.json` в поле `image`, например `textures/gui/spawn_selector/forest.png`.

## Важные замечания

- Данные выбранных игроков хранятся в `config/spawn-selector/spawndata.json`.
- Если конфиг повреждён, исходный файл сохраняется как `*.broken`, затем создаётся конфигурация по умолчанию.
- При сбросе выбора команда игрока очищается.
- Проект нужно собрать и проверить на реальном сервере Fabric 26.2 перед установкой в рабочий мир. Эта версия ещё не прошла локальную Gradle-сборку в данной среде.
