# Spawn Selector — Fabric 26.2

Мод добавляет обязательный выбор места появления при первом входе на сервер:
1. Европа.
2. Африка.
3. Австралия.
4. Свободное выживание без команды — случайная безопасная точка суши.

## Сборка

- Minecraft 26.2
- Fabric Loader и Fabric API из `gradle.properties`
- Java 25

В Windows: `gradlew.bat build`
В Linux/macOS: `./gradlew build`

Готовый JAR появится в `build/libs`.

## Администраторские команды

- `/spp list` — список точек.
- `/spp set 1 <позиция>` — установить координаты первой командной точки на текущую позицию.
- `/spp set 2 <позиция>` — установить вторую точку.
- `/spp set 3 <позиция>` — установить третью точку.
- `/spp setname <номер 1–3> <название>` — изменить название.
- `/spp teams` — показать численность команд.
- `/spp reset <игрок>` — сбросить выбор игрока и убрать его из команды.

Команды доступны операторам. Команда `/spp set` устанавливает точку по текущей позиции игрока и поэтому выполняется только из игры; остальные команды можно вызывать из консоли, если они не требуют присутствия игрока.

## Конфигурация

После первого запуска появится `config/spawn-selector/spawnpoints.json`.

- `maxPlayersPerTeam: 0` отключает абсолютный лимит команды.
- `maxTeamImbalance: 3` запрещает выбор, который создаст перевес более трёх игроков относительно самой малочисленной команды.
- `radius` задаёт радиус поиска безопасной точки вокруг координат командного спавна.

Четвёртый вариант использует случайный выбор безопасной суши. Мод отбрасывает воду, лаву/огонь, опасные блоки, пустоту под ногами и места без свободного пространства. Если подходящее место не найдено, выбор не фиксируется и игрок может попробовать снова.

## Изображения меню

Изображения находятся в `src/main/resources/assets/spawnselector/textures/gui/spawn_selector/` и используются клиентом в меню выбора:

- `forest.png` — Европа (первая территория).
- `mountains.png` — Африка (вторая территория).
- `plains.png` — Австралия (третья территория).
- `free_survival.png` — Свободное выживание.

Все изображения отображаются целиком с сохранением пропорций; лишние области не обрезаются и изображение не растягивается. Если изображение отсутствует, фон предпросмотра остаётся чёрным.

## Важные замечания

- Данные выбранных игроков хранятся в `config/spawn-selector/spawndata.json`.
- Если конфиг повреждён, исходный файл сохраняется как `*.broken`, затем создаётся конфигурация по умолчанию.
- При сбросе выбора команда игрока очищается.
- Проект следует собрать и проверить на сервере Fabric 26.2 перед установкой в рабочий мир.
