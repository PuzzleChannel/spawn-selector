Изображения предпросмотра команд
================================

Положите сюда три PNG-изображения (рекомендуется 16:9, например 640x360):
- forest.png — референс лесной долины
- plains.png — референс равнинного поселения
- mountains.png — референс горного плато

Имена и пути изображений задаются в config/spawn-selector/spawnpoints.json.
Для замены достаточно положить собственный PNG под тем же именем.
